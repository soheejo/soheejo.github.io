    경비명세서 작성 방법

    1. + 새 명세서 → 국내 / 해외 출장 또는 주유비 · 통행료 선택
    2. 출장자·출장지·목적·기간 입력, 출발·도착 오전/오후 선택(필수)
    3. 직급에 맞는 지급규정 단가와 오후 출발·오전 도착 50%·휴일 2배 일당이 자동 계산
    4. 이동 내역(월/일·출발지·도착지·교통수단·경비) 입력
    5. 📋 다우오피스용 복사 → 다우오피스 기안 본문에 Ctrl+V

    처음 한 번 설정에서 내 부서·직급·이름을 저장해 두면 새 명세서마다 자동으로 채워집니다.
